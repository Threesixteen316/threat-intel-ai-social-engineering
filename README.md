# AI-Driven Social Engineering Threat Intelligence Report  This repo contains a CTI report on AI-powered social engineering attacks targeting West African organisations, completed for The Purpose Protocol Cohort 1.
## Summary
- **What it covers**: How generative AI is used to create convincing phishing emails, voice clones, and deepfake calls to bypass traditional security controls.
- **Why it matters**: These attacks are low-cost, scalable, and effective against Nigerian and West African banks, universities, and SMEs where phone and WhatsApp verification is common.
- **Key findings**: Attackers now use AI to eliminate typos, match tone, and exploit public data from LinkedIn and social media to personalise scams at scale.
- **Recommendations**: Implement call back policies, enforce MFA with passkeys, and run quarterly training using real AI-generated examples. A simple "safe word" system can block most impersonation attempts.
- **Audience**: Security teams, IT managers, and business leaders in West Africa who need actionable, low-budget defenses.
